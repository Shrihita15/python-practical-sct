Practical 9 - Apache Airflow on Docker
Steps
1.	Open Docker Desktop and wait until it is running.
2.	Open cmd, make sure you are in the C drive, then create and enter the project folder:
mkdir airflow-docker
cd airflow-docker
3.	Download the docker-compose.yaml file from the official Airflow documentation and save it inside the airflow-docker folder.
4.	Open Notepad and type this one line: AIRFLOW_UID=50000
5.	Click File, then Save As. Choose the airflow-docker folder, set Save as type to All Files, type the file name .env and click Save.
6.	In cmd (inside airflow-docker), initialize Airflow. The dags, logs and plugins folders get created automatically here:
docker compose up airflow-init
7.	Wait until it finishes (it ends with exit code 0). Then start Airflow in the background (the flag is -d):
docker compose up -d
8.	Wait until cmd shows all containers as Started.
9.	Open Docker Desktop and click Containers in the left menu.
10.	You will see airflow-docker in the list with a small arrow on its left. Click the arrow to expand it.
11.	A list of containers appears (postgres, redis, scheduler, worker, triggerer and the airflow webserver / api-server). Wait until they all show Running.
12.	Find the Airflow webserver (api-server) container and look at its Port(s) column. Click the 8080:8080 link.
13.	Your browser opens the Airflow login page (http://localhost:8080). Log in with username airflow and password airflow.
14.	Open VS Code, open the airflow-docker folder, and create a new file named simple_dag.py inside the dags folder.
15.	Paste the code below into simple_dag.py and save it:
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.bash import BashOperator
 
# Define default arguments for the DAG
default_args = {
    'owner': 'airflow',
    'depends_on_past': False,
    'start_date': datetime(2026, 1, 1),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}
 
# Instantiate the DAG
with DAG(
    'my_first_simple_dag',
    default_args=default_args,
    description='A simple tutorial DAG',
    schedule=None,  # Manual trigger only
    catchup=False,
) as dag:
 
    # Task 1: Print Hello
    task_hello = BashOperator(
        task_id='print_hello',
        bash_command='echo "Hello World from Airflow!"',
    )
 
    # Task 2: Print Date
    task_date = BashOperator(
        task_id='print_date',
        bash_command='date',
    )
 
    # Set task dependency (task_hello runs before task_date)
    task_hello >> task_date

16.	Go back to the Airflow page in the browser and refresh it. Wait a short while and my_first_simple_dag will appear in the DAG list.
17.	Turn the toggle of my_first_simple_dag ON (enable it).
18.	Click the Trigger (play) button to run it manually.
19.	Click the DAG name and open Graph View. You will see print_hello followed by print_date, both turning green (Success).
20.	Click print_hello and open Logs: it shows Hello World from Airflow! Then click print_date and open Logs: it shows the current date.
Short answers
Purpose of the folders: dags holds the DAG Python files, logs stores task and scheduler logs, plugins holds custom operators and hooks.
Why .env is needed on Windows: the compose file reads AIRFLOW_UID to set the user the containers run as. Windows has no Linux user ID, so we set it manually; otherwise Docker shows a warning and file permission problems can occur in the shared folders.
Observation: the Docker environment started successfully, my_first_simple_dag ran with status Success, both tasks succeeded, and the logs showed the Hello World message and the date. Airflow represents a workflow as a DAG made of tasks, and dependencies (task_hello >> task_date) decide the order.

## 10. PYTHON CODE: sales_data_pipeline_dag.py

from datetime import datetime
import csv
import os

from airflow import DAG
from airflow.operators.python import PythonOperator


# File Locations
DATA_FOLDER = "/opt/airflow/dags/data"
INPUT_FILE = os.path.join(DATA_FOLDER, "sales.csv")
CLEANED_FILE = os.path.join(DATA_FOLDER, "cleaned_sales.csv")


# Task 1: Start Pipeline
def start_pipeline():
    print("Sales Data Pipeline Started")


# Task 2: Check Dataset
def check_dataset():
    if not os.path.exists(INPUT_FILE):
        raise FileNotFoundError("sales.csv was not found.")

    with open(INPUT_FILE, "r") as file:
        reader = csv.DictReader(file)
        rows = list(reader)

    print("Dataset found successfully.")
    print("Number of records:", len(rows))


# Task 3: Clean Data
def clean_data():
    clean_rows = []

    with open(INPUT_FILE, "r") as file:
        reader = csv.DictReader(file)
        fieldnames = reader.fieldnames

        for row in reader:
            if all(value.strip() != "" for value in row.values()):
                clean_rows.append(row)

    with open(CLEANED_FILE, "w", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(clean_rows)

    print("Data cleaning completed.")
    print("Clean records:", len(clean_rows))
    print("Output:", CLEANED_FILE)


# Task 4: Validate Data
def validate_data():
    invalid_records = []

    with open(INPUT_FILE, "r") as file:
        reader = csv.DictReader(file)

        for row in reader:
            if row["quantity"] == "" or row["price"] == "":
                continue

            quantity = int(row["quantity"])
            price = float(row["price"])

            if quantity <= 0 or price <= 0:
                invalid_records.append(row)

    print("Validation completed.")
    print("Invalid records found:", len(invalid_records))

    for record in invalid_records:
        print(record)


# Task 5: Generate Summary
def generate_summary():
    total_sales = 0
    total_records = 0

    with open(CLEANED_FILE, "r") as file:
        reader = csv.DictReader(file)

        for row in reader:
            quantity = int(row["quantity"])
            price = float(row["price"])

            total_sales += quantity * price
            total_records += 1

    average_sales = (
        total_sales / total_records
        if total_records > 0
        else 0
    )

    print("----- SALES SUMMARY -----")
    print("Total Records:", total_records)
    print("Total Sales:", total_sales)
    print("Average Sales:", average_sales)


# DAG Definition
with DAG(
    dag_id="sales_data_pipeline",
    description="Sales Data Processing Workflow",
    start_date=datetime(2026, 1, 1),
    schedule=None,
    catchup=False,
    tags=["ETDE", "Practical 10"],
) as dag:

    start_task = PythonOperator(
        task_id="start_pipeline",
        python_callable=start_pipeline,
    )

    check_task = PythonOperator(
        task_id="check_dataset",
        python_callable=check_dataset,
    )

    clean_task = PythonOperator(
        task_id="clean_data",
        python_callable=clean_data,
    )

    validate_task = PythonOperator(
        task_id="validate_data",
        python_callable=validate_data,
    )

    summary_task = PythonOperator(
        task_id="generate_summary",
        python_callable=generate_summary,
    )

    # Task Dependencies
    start_task >> check_task
    check_task >> [clean_task, validate_task]
    [clean_task, validate_task] >> summary_task

def search_catalog(catalog, column_name, search_value):

    if column_name not in catalog.columns:
        print("Column not found:", column_name)
        return pd.DataFrame()

    search_value = str(search_value).lower()

    def matches(value):
        if isinstance(value, list):
            return any(
                search_value in str(item).lower()
                for item in value
            )

        if pd.isna(value):
            return False

        return search_value in str(value).lower()

    result = catalog[
        catalog[column_name].apply(matches)
    ]

    return result
