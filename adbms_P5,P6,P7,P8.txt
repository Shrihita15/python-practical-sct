SELECT
    SDO_GEOM.SDO_DISTANCE(
        a.Location,
        b.Location,
        0.005
    ) AS Distance_Metres
FROM Campus_Place a,
     Campus_Place b
WHERE a.Place_ID = 1
AND b.Place_ID = 2;

Approximately 223.61 coordinate units.

Distance = SQRT((200 - 0)^2 + (100 - 0)^2)

Q19.9. FIND THE NEAREST CLINIC TO CLINIC C
==================================================

SELECT Clinic_Name, Distance_Metres
FROM (
    SELECT
        c.Clinic_Name,
        SDO_GEOM.SDO_DISTANCE(
            c.Location,
            x.Location,
            0.005
        ) AS Distance_Metres
    FROM Clinic c,
         Clinic x
    WHERE x.Clinic_ID = 3
    AND c.Clinic_ID <> 3
    ORDER BY Distance_Metres
)
WHERE ROWNUM = 1;

Clinic B — approximately 5830.95 coordinate units.
